BIRTHDAY WEBSITE - upload everything in this folder to the ROOT of a GitHub repository.
1. Create a public repo, upload ALL files (index.html must be at the top level).
2. Settings > Pages > Deploy from a branch > main / (root) > Save.
3. Site address: https://YOUR-USERNAME.github.io/YOUR-REPO/
4. For the WhatsApp preview, open index.html and replace https://USERNAME.github.io/REPO/
   with your real address (og:url, og:image, twitter:image). Keep thumbnail.jpg in the root.
5. Music: song1.mp3 starts at 01:48 and loops back to 01:48 (see SONGS in script.js).
   Music is off on the first page, starts when you press next, and resets on restart.
